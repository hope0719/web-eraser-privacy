1概述Overview

《网页橡皮擦》（以下简称"本扩展"）的开发者高度重视用户隐私。本扩展的唯一用途是在用户主动开启"橡皮擦"模式后，提供一个可视化的擦除交互：鼠标光标变成橡皮擦，在网页元素上左右蹭动即可将其擦除，被擦元素先淡出再从页面中移除，下方内容自动上移。 The developer of "Web Eraser" (hereinafter "the Extension") takes user privacy seriously. The sole purpose of the Extension is to provide a visual erasing interaction after the user actively enables "eraser" mode: the cursor turns into an eraser, and rubbing left and right over a page element erases it—the erased element fades out and is then removed from the page, with content below automatically shifting up.

核心承诺Core Commitment 本扩展不收集、不上传、不分享、不出售任何用户个人信息或网页内容。所有擦除操作均在你的浏览器本地完成，不会向任何服务器发送数据。 The Extension does not collect, upload, share, or sell any user personal information or webpage content. All erasing operations are performed locally in your browser and no data is sent to any server.

3权限说明Permissions

为提供"橡皮擦"功能，本扩展在清单（manifest）中申请了主机权限 <all_urls>。理由如下： To provide the "eraser" feature, the Extension requests the host permission <all_urls> in its manifest. The reasons are as follows:

  • 用户可能访问任意网址，因此需要将内容脚本（content script）注入到当前页面；Users may visit any URL, so a content script must be injected into the current page;
  • 注入后，扩展会读取页面元素的位置与边界，以便在光标悬停时高亮目标元素；After injection, the Extension reads the position and boundaries of page elements to highlight the target element on cursor hover;
  • 当用户蹭动擦除时，扩展执行淡出动画并将该元素从 DOM 中移除，下方内容自动上移；When the user rubs to erase, the Extension plays a fade-out animation and removes the element from the DOM, with content below shifting up automatically;
  • 上述行为仅在用户主动点击工具栏图标或按下快捷键开启橡皮擦模式时才会运行，扩展不会在后台自动运行或自动处理页面。The above behavior runs only when the user actively clicks the toolbar icon or presses the shortcut to enable eraser mode; the Extension does not run automatically in the background or process pages on its own.
权限最小化Permission Minimization 除实现"擦除网页元素"这一单一用途所必需的权限外，本扩展不申请任何其他权限，也不会将这些权限用于与单一用途无关的场景。 Beyond the permissions essential to the single purpose of "erasing webpage elements," the Extension requests no other permissions and will not use them for purposes unrelated to that single purpose.

4数据存储与远程代码Data Storage & Remote Code

本地处理，无远程代码Local Processing, No Remote Code

  • 本扩展完全基于 Manifest V3 构建，所有 JavaScript / Wasm 代码均随扩展包一同发布；The Extension is built entirely on Manifest V3; all JavaScript/Wasm code ships within the extension package;
  • 不使用远程代码：不包含指向外部文件的 <script> 引用、外部模块或 eval() 执行的字符串；No remote code: it contains no <script> references to external files, no external modules, and no eval()-executed strings;
  • 不向远程服务器拉取或执行任何脚本；It does not fetch or execute any script from a remote server;
  • 擦除结果仅存在于当前页面会话中，刷新或离开页面后即消失，不写入任何持久化存储。Erasing results exist only in the current page session and disappear after refresh or navigation; nothing is written to persistent storage.
